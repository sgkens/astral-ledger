# Astral Ledger

Production-ready baseline scaffold for a Stellaris codex + empire builder platform.

## Included
- `apps/web` — SvelteKit-style scaffold
- `apps/api` — Cloudflare Worker API with D1-first trait endpoints
- `packages/contracts` — shared TypeScript contracts
- `packages/db` — migrations and D1 query helpers
- `tools/powershell` — ingest module scaffold
- `data/seed` — seed trait record
- `docs` — roadmap and D1 setup notes

## Current slice

- D1 schema
